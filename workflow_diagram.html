Mechanism-to-Excel Reproducer

The tool takes a parsed actuarial model and a plain-language description of a mechanism, and rebuilds that mechanism as a working Excel calculation. Four stages — the AI does the reasoning, you stay in control at the two confirmation points, and the file is built automatically.
The two confirmation points (stages 1 and 2) keep an actuary in control of what gets modelled before any spreadsheet is built. Everything the AI cites comes from the model's own source code — it does not invent figures.
